MARGIN — Rich Anonymous Academic Project Page

Usage: open index.html in a modern browser, or run `python3 -m http.server 8000` from this folder.
All images, charts, task data and keyframe replay MP4s are local assets.

Sources: current November 16 main-paper PDF for Figure 2, 3 and 6; archived paper_cvpr2027_20261109 experimental source ZIP for supplementary plots and data.

Task explorer: 80 LIBERO-Pro, 90 LIBERO-90, seven Robosuite tasks. LIBERO-Pro final values are the task-equal aggregation of the 43 unrepaired ASPIRE incumbents and the two accepted MARGIN revision evaluations for each of the 37 refined tasks. LIBERO-90 and Robosuite explorer show original reproduction runs. Do not present these as 177 identical paired refinement studies.

Videos: three existing archived keyframe replay MP4s, not continuous raw simulation videos.

The content is not a public release and no sensitive author data or private repository URLs are included. CVPR 2027 submissions prohibit external project links expanding the paper; do not link this website from the double-blind review PDF.
